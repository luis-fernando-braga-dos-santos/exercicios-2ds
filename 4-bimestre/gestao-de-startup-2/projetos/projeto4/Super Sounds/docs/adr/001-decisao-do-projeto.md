# ADR 001 — Escolha do Super Sounds como produto

ADR 001 — Utilização de HTML, CSS e JavaScript

Data: 24/11/2026

Status: Aceita

Contexto

Precisava escolher tecnologias para desenvolver um site de música. O objetivo era criar uma página simples, funcional e que permitisse a reprodução de músicas.

Decisão

Decidi utilizar HTML para estruturar o site, CSS para desenvolver o visual e JavaScript para implementar as funcionalidades e controlar a reprodução das músicas.

Consequências
Positivas
Tecnologias simples de utilizar.
Não é necessário utilizar ferramentas complexas.
Fácil manutenção do código.
Permite desenvolver uma interface personalizada.
Negativas
Algumas funcionalidades exigem mais código JavaScript.
O projeto pode precisar de melhorias para suportar muitos usuários.
Não possui banco de dados para armazenar informações.
