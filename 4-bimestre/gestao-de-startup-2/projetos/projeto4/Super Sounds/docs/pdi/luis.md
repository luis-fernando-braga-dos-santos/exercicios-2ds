# PDI — Luis — Super Sounds

PDI — Meu Desenvolvimento Individual

Período: 4º bimestre

ONDE ESTOU

Tenho conhecimentos básicos de HTML, CSS e JavaScript e consigo desenvolver páginas simples, mas ainda tenho dificuldades em algumas funcionalidades.

ONDE QUERO CHEGAR

Conseguir desenvolver corretamente a reprodução de músicas utilizando JavaScript até o final do bimestre.

O QUE ME FALTA

Preciso melhorar meus conhecimentos em JavaScript, principalmente na manipulação de elementos HTML e nos controles de áudio.

O QUE VOU FAZER
Semana 1: estudar manipulação do DOM com JavaScript.
Semana 2: praticar os comandos de reprodução e pausa de áudio.
Semana 3: implementar e testar o player de músicas.
Semana 4: explicar para um colega como funciona a reprodução de áudio com JavaScript.
