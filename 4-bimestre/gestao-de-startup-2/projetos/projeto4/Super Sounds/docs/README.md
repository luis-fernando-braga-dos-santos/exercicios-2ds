🎵 Super Sounds
📌 Sobre o projeto

O Super Sounds é um site de música desenvolvido com o objetivo de oferecer aos usuários uma maneira simples e organizada de acessar músicas. O projeto busca proporcionar uma experiência agradável, com uma interface fácil de utilizar.

🎯 Objetivo do projeto

Criar uma plataforma musical que permita aos usuários encontrar e ouvir músicas de maneira prática, com uma navegação simples e intuitiva.

🚀 Funcionalidades
Acesso à página inicial.
Organização das músicas.
Reprodução de músicas.
Interface simples e intuitiva.
Navegação pelo site.
🛠️ Tecnologias utilizadas
HTML — estrutura das páginas.
CSS — aparência e organização visual.
JavaScript — funcionalidades e interações.
